# Dotfiles

This repository contains my personal configuration files, environment settings, and application preferences.
The configurations are automated and synchronized across systems using [chezmoi](https://www.chezmoi.io/).

## Core Stack

* **Dotfiles Manager:** [chezmoi](https://www.chezmoi.io/)
* **File Manager:** [Yazi](https://yazi-rs.github.io/)
* **Shell:** [Fish Shell](https://fishshell.com/)
    - **Prompt:** [Tide](https://github.com/IlanCosman/tide)
* **Terminal:** [kitty](https://sw.kovidgoyal.net/kitty/)
